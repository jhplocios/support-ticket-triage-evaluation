## Evidence limits

The original recordings lack provider-returned model IDs, request IDs, and prompt versions. The configured model name and historical price assumptions come from source configuration. No missing provenance fields have been backfilled.

The example email addresses in the tickets were confirmed by the author to be fictional. They are retained consistently in the inputs and recorded prompts.

The project is a learning experiment, not a deployed product. See [RESULTS.md](RESULTS.md) for the measurement limits.
